# Fraudulent Transaction Monitor

An end-to-end fraud-detection pipeline built in Python. Graduate project at Arizona State University.

## Overview
- Engineered a pipeline to ingest, clean, and preprocess synthetic transaction data.
- Developed deep-learning anomaly-detection models to flag fraud-related transactions.
- Added automated validation and monitoring alerts to surface anomalies for faster investigation.

## Pipeline
```
Synthetic transactions -> Ingestion -> Cleaning & preprocessing -> Deep-learning anomaly detection -> Validation -> Monitoring alerts
```

## Tech stack
Python · Deep Learning · Anomaly Detection · ETL
